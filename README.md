# AgroCart Connect

"Create a modern, fast, and fully responsive agro-commerce landing page (similar to an agricultural tool and product shop) using React, Tailwind Shimmer/UI, and Lucide icons. The app must include: 1. A striking Hero Banner with a promotional tagline and quick category navigation. 2. A Product Grid section that dynamically fetches products from a Supabase products table (columns: id, name, price, image_url, category, description). 3. An interactive Order Checkout Modal where customers can enter their Name, Phone Number, Full Address, and Quantity, which then saves the order directly into a Supabase orders table (columns: id, customer_name, phone, address, product_name, quantity, total_price, status, created_at). 4. A simple Admin / Product Management Page (e.g., /admin) with a form to insert new products directly into the Supabase database. 5. Smooth transitions, clean green/agro themed styling, and high usability on mobile devices."
